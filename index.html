What the agent gets

Six tools, each answering a question a writer or a growth team asks in a normal week. None needs an account or a key.

tool evidence question it answers
get_trending trends What people are searching for right now, filtered to a niche
get_keyword_research autocomplete Which keyword candidates are real, and the slot each one holds
get_serp_snapshot serp Who ranks today, the news pack beside them, how contested the term is
get_technical_audit http What is wrong with the page in front of a crawler
get_backlinks estimate Which pages link to the domain, confirmed by reading them
get_traffic estimate Referring domains, confirmed backlinks, the pages the engine shows

What the keyless path cannot give you

The server prints these limits so an agent does not quote a number it cannot back up.

Monthly search volume stays out. It needs clickstream and advertising data that no public endpoint exposes. The autocomplete position takes its place: a real measure of how strongly people type a term.

The backlink index is a sample. The keyless path finds pages that mention the domain and confirms each link by fetching the page. It finds fewer links, takes longer, and each link it reports is one it read.

Traffic comes back as reach. Without a CapSolver key, get_traffic returns confirmed backlinks, referring domains and indexed pages. The visit count is missing, and the response says so.
